## 🛠️ How to Run Tasks

### Task 1: Loan EMI Calculator
- **Desktop GUI**: `python Task1_EMI_Calculator/gui_calculator.py`
- **Web UI**: Open `Task1_EMI_Calculator/index.html` in any browser
- **CLI**: `python Task1_EMI_Calculator/emi_calculator.py`

### Task 2: Public REST API Data Fetcher
- **Desktop GUI**: `python Task2_API_Data_Fetcher/gui_fetcher.py`
- **Web UI**: Open `Task2_API_Data_Fetcher/index.html` in any browser

### Task 3: Simple Blog App + Local Storage
